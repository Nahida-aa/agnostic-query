## Build once, query anywhere

The same `QuerySchema` drives Drizzle, Kysely, raw SQL (PostgreSQL), or any future adapter. Not an ORM replacement — just reduces the boilerplate of building, validating, and translating query conditions across the stack.

**Runtime-agnostic** — plain data that work in clients, servers, and edge runtimes. Serialize to JSON, transmit over HTTP, consume on any platform.

## Quick Start

```bash
bun add agnostic-query
```

```ts
import { aq } from 'agnostic-query'

interface User {
  name: string
  age: number
  status: string
}

const schema = aq<User>()
  .where('name', 'eq', 'Alice')
  .where('age', 'gte', 18)
  .orderBy('name', 'asc')
  .limit(20)
  .toJSON()
```
